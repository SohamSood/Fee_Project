## 📌 Project Brief

**Tribute.A.I.** is my **first web development project**, crafted to pay tribute to celebrated Indian heroes, visionaries, and icons who shaped history through bravery, dedication, and service to humanity.

This project was built from the ground up to practice fundamental frontend engineering concepts, including responsive grid layouts, multi-page routing with relative linking, accessible modal dialogs, and clean UI styling.

---

## 🌟 Featured Tributes

- 🇮🇳 **Captain Vikram Batra (Param Vir Chakra)** — Hero of the 1999 Kargil War known for his supreme sacrifice and iconic words, *"Yeh Dil Maange More!"*
- ✊ **Shaheed Bhagat Singh** — Fearless revolutionary who inspired India's struggle for independence.
- 🏢 **Ratan Tata** — Visionary industrialist, nation builder, and philanthropist.
- 🎵 **Lata Mangeshkar** — The legendary "Nightingale of India" whose voice moved generations.

---

## ✨ Key Features

- **📱 Fully Responsive Design**: Seamless viewing experience across mobile devices, tablets, and desktops using Bootstrap 4's grid system.
- **🎨 Interactive Hero Carousel**: Smooth-transitioning banner carousel highlighting featured figures.
- **📖 Detailed Tribute Story**: Dedicated showcase page with timeline highlights, military achievements, and inspiring quotes.
- **🔐 Interactive Modals**: Clean popup modals for user Login and Account Registration with client-side form handling.
- **📬 Multi-Page Architecture**: Well-structured navigation linking Home, About, Tribute Stories, and Contact pages with zero broken references.

## 🚀 Running Locally

To run this project on your machine without any external dependencies or build tools:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/SohamSood/Fee_Project.git
   ```
2. **Navigate into the folder**:
   ```bash
   cd Fee_Project
   ```
3. **Open the project**:
   - Simply double-click `index.html` or open it with your favorite browser!
